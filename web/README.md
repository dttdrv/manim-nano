# manim-nano — browser demo

Renders a plain-English description into an animated GIF **entirely in your
browser** via WebAssembly. No server, no network, no API key — free and offline.

The page calls the Rust export
`render_gif(text: &str, width: u32, height: u32, fps: u32) -> Vec<u8>`
(compiled from `src/wasm.rs`) and shows the returned GIF.

## 1. Build the WebAssembly glue

The TypeScript imports `../pkg/manim_nano.js`, which is generated from the crate.
Produce it with **wasm-pack** (recommended):

```sh
# from this `web/` directory
npm install                 # installs TypeScript (for the type check only)
npm run build:wasm          # -> web/pkg/{manim_nano.js, manim_nano_bg.wasm, ...}
```

`build:wasm` runs, from the repo root:

```sh
wasm-pack build . --target web --features wasm --out-dir web/pkg
```

If you don't have `wasm-pack`, install it once with
`cargo install wasm-pack` (or see https://rustwasm.github.io/wasm-pack/).

### Manual alternative (no wasm-pack)

```sh
rustup target add wasm32-unknown-unknown
cargo build --lib --release --features wasm --target wasm32-unknown-unknown
wasm-bindgen \
  target/wasm32-unknown-unknown/release/manim_nano.wasm \
  --target web --out-dir web/pkg
```

(`wasm-bindgen-cli` must match the `wasm-bindgen` crate version:
`cargo install wasm-bindgen-cli`.)

## 2. Type-check the TypeScript (optional, recommended)

```sh
npm run typecheck      # tsc --noEmit, using the strict tsconfig.json
```

> Note: the `import init, { render_gif } from "../pkg/manim_nano.js"` line is
> marked with `@ts-expect-error` because `pkg/` only exists after step 1. Once
> built, the generated `.d.ts` provides full types.

## 3. Serve the page

Browsers won't load ES modules or `.wasm` from `file://`, so serve over HTTP:

```sh
npm run serve          # python3 -m http.server 8080
# then open http://localhost:8080/
```

(Any static file server works.)

## Files

| File              | Purpose                                                        |
| ----------------- | -------------------------------------------------------------- |
| `index.html`      | Textarea + Render button + `<img>` output; loads the module.   |
| `src/main.ts`     | Strict TypeScript: boots wasm, calls `render_gif`, shows GIF.  |
| `tsconfig.json`   | Strict config (ES2022, `bundler` resolution).                  |
| `package.json`    | Scripts for building the wasm glue, type-checking, serving.    |
| `pkg/`            | Generated by step 1 (gitignored).                              |
